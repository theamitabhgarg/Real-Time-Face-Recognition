# Real-Time Face Recognition System

A real-time face recognition system built with **Python, OpenCV, KNN, Haar Cascade Classifiers, and NumPy**. The application uses a webcam to detect faces, collect face data, and recognize registered individuals in real time.

## Features

* Real-time webcam face detection
* Haar Cascade-based face detection
* Face dataset generation from webcam frames
* NumPy-based face data storage
* Real-time face recognition
* Bounding boxes around detected faces
* Personalized name labels for recognized individuals
* Lightweight and suitable for real-time execution

## How It Works

The project follows a simple four-stage computer vision pipeline:

```text
Webcam
   ↓
Video Capture
   ↓
Face Detection
   ↓
Face Data Collection
   ↓
Face Recognition
   ↓
Name displayed around detected face
```

### 1. Webcam Test

`video read.py` verifies that the system can access and read frames from the connected webcam.

### 2. Face Detection

`face_detection.py` uses OpenCV's Haar Cascade Classifier to detect faces in real-time.

The detected face is surrounded by a bounding box and extracted from the video frame.

### 3. Face Data Collection

`face_data.py` captures multiple samples of a person's face from the webcam and stores the extracted face information as a NumPy array.

The collected data is stored locally in:

```text
face_dataset/
```

For example:

```text
face_dataset/
└── person_name.npy
```

### 4. Face Recognition

`face_recognition.py` loads the stored face dataset and compares detected faces against the registered data.

When a match is found, the person's name is displayed along with a bounding box.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Real-Time-Face-Recognition.git
cd Real-Time-Face-Recognition
```

### 2. Create a virtual environment

Windows:

```powershell
python -m venv venv
```

Activate it:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
pip install -r requirements.txt
```

## Usage

### Step 1 — Test the webcam

```powershell
python "video read.py"
```

Press `q` to exit the webcam window.

### Step 2 — Test face detection

```powershell
python face_detection.py
```

The application will detect faces using the Haar Cascade classifier.

Press `q` to exit.

### Step 3 — Collect face data

```powershell
python face_data.py
```

Enter the name of the person when prompted.

The program will capture face samples and save the resulting data locally.

### Step 4 — Run face recognition

```powershell
python face_recognition.py
```

The application will access the webcam, detect faces, and compare them against the locally collected face data.

Press `q` to exit.

## Face Detection Method

This project uses OpenCV's **Haar Cascade Classifier** for face detection.

The classifier works by scanning the image at different positions and scales to identify patterns associated with human faces.

The classifier used in this project is:

```text
haarcascade_frontalface_alt.xml
```

## Data Privacy

Face datasets generated by this project contain biometric information and should be treated as sensitive data.

For this reason, locally generated `.npy` face datasets are excluded from version control.

Do not upload personal face datasets to a public repository.
